キーボードとコントローラーの入力管理を行うクラス

毎フレーム最初に

	Update();

を呼ぶこと


---------------------------------------------------------
基本的な使い方
---------------------------------------------------------

Input input;

while (ゲームループ)
{
	input.Update();

	入力判定
}


---------------------------------------------------------
キーボード入力
---------------------------------------------------------

GetKeyPress()

	キーを押している間true

	例

		if (input.GetKeyPress(VK_A))

	用途

		移動
		カーソル移動
		長押し判定


GetKeyTrigger()

	キーを押した瞬間だけtrue

	例

		if (input.GetKeyTrigger(VK_SPACE))

	用途

		ジャンプ
		決定ボタン
		メニュー選択


GetKeyRelease()

	キーを離した瞬間だけtrue

	例

		if (input.GetKeyRelease(VK_SPACE))

	用途

		チャージ解除
		ボタン離し判定


---------------------------------------------------------
コントローラーボタン入力
---------------------------------------------------------

GetButtonPress()

	ボタンを押している間true

	例

		if (input.GetButtonPress(XINPUT_A))


GetButtonTrigger()

	ボタンを押した瞬間だけtrue

	例

		if (input.GetButtonTrigger(XINPUT_A))


GetButtonRelease()

	ボタンを離した瞬間だけtrue

	例

		if (input.GetButtonRelease(XINPUT_A))


---------------------------------------------------------
アナログスティック
---------------------------------------------------------

GetLeftAnalogStick()

	左スティックの入力取得

	戻り値

		X : -1～1
		Y : -1～1

	例

		auto stick =
			input.GetLeftAnalogStick();

		float moveX = stick.x;


GetRightAnalogStick()

	右スティックの入力取得

	戻り値

		X : -1～1
		Y : -1～1


---------------------------------------------------------
トリガー入力
---------------------------------------------------------

GetLeftTrigger()

	LT入力取得

	戻り値

		0.0f ～ 1.0f


GetRightTrigger()

	RT入力取得

	戻り値

		0.0f ～ 1.0f


---------------------------------------------------------
振動
---------------------------------------------------------

SetVibration(
	frame,
	powor
)

	frame

		振動継続時間

	powor

		振動強度(0～1)

	例

		input.SetVibration(
			30,
			1.0f
		);

	30フレーム最大振動


---------------------------------------------------------
よく使う入力例
---------------------------------------------------------

Aキーを押している

	input.GetKeyPress(VK_A)


スペースキーを押した瞬間

	input.GetKeyTrigger(VK_SPACE)


Aボタンを押した瞬間

	input.GetButtonTrigger(XINPUT_A)


左スティック入力取得

	input.GetLeftAnalogStick()


コントローラー振動

	input.SetVibration()
